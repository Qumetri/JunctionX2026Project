# Component review checklist

## How to use this file

Work through the demo at `component-demo/` (run `npm run dev` there). Each live example has an ID (C01 to C121) shown in its title, and the same IDs appear here in order.

For each component:
- Tick **Keep** if it works and belongs in the app.
- Tick **Needs fix** if it works poorly or looks wrong, and write what to change under **Notes**.
- Leave both boxes empty if you have not reviewed it yet.
